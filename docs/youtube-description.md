Title: Provenance — Taskmaster Agent Fleet | Google "All Things Agentic" Hackathon

Description:

Provenance is a fleet of Gemini agents that reads new health research every night, checks whether it actually challenges the scoring algorithm in my iOS app (synqology), and opens a tested, human-reviewed pull request — it never merges on its own.

Built solo for the Taskmaster track of Google's "All Things Agentic" hackathon.

Stack: Google Agent Development Kit (ADK) · Gemini 3.5 Flash-Lite + Gemini 3.7 Flash on Vertex AI · Cloud Run Jobs · Cloud Scheduler · Firestore · GitHub Actions + Workload Identity Federation
