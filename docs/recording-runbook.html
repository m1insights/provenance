If a take goes wrong

Three things that could misbehave live, and what to do.

GCP Console signed out

The Logs Explorer and Cloud Run tabs need a live session — sign in before you start recording, not mid-take. A login redirect on camera is the one shot you can't cut around.

Content queue unavailable

If you were going to run a live command for the reel beat and it fails, just play the reel already in the library folder and skip the command.

Console 403

Your write cookie expired. POST the token to /unlock again — it's a 12-hour cookie.
