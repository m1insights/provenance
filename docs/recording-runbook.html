0:30It reads your code to decide what to research
Run.venv/bin/python -m provenance agenda --detail
Say

Provenance is never told what to research. It reads the algorithm's own source and works out what literature would bear on it. Cardio credits a day at twenty minutes and wants three days a week — so it goes hunting for bout-duration and weekend-warrior studies. Not exercise is good for you. The literature that could prove that specific number wrong.

2:45The trap — best 20 seconds you have
Say

The obvious fix is to restore the old ratio, which means a denominator of one point three three. That would have been worse. The code divides by it and truncates it to an integer — so every shift worker gets capped at seventy-five percent of the score they earned. Permanently. And no test fails.

Say

It's one point zero now, with a test asserting the shift bar stays strictly easier than the default — because pinning each number separately is exactly what let them collide.

3:40The human, and the close
Screen

Console showing the mvpa finding, approved. Then the architecture diagram.

Say

Nothing merges. There is no merge function in this codebase — not a rule in a prompt, an absent tool. I approve or I reject, and a rejection goes back to the agents as guidance.

Say

Gemini for appraisal, ADK for the fleet, Firestore, Cloud Run, Pub/Sub, Scheduler. And Claude Opus auditing what Gemini writes — because one model checking its own work isn't a check. It reads the literature so the algorithm doesn't fall behind it. It shows its working every time. And the most useful thing it does is refuse.

If a take goes wrong

Three things that could misbehave live, and what to do.

Hook silent

Both PRs are audited, so it should be silent. To make it speak, delete the audit comment on synq_insights#1 before the take — the hook keys on that marker.

Storyteller slow

It calls Gemini twice; ~40s is normal. Talk over it, or cut to the rendered slides you already have in renderer/out-real/.

Console 403

Your write cookie expired. POST the token to /unlock again — it's a 12-hour cookie.
